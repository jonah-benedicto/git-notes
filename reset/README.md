# Reset

## Move HEAD to commit and keep staged changes
```bash
git reset --soft <commit>
```

## Move HEAD to commit and unstage changes
```bash
git reset --mixed <commit>
```

## Move HEAD to commit and discard changes
```bash
git reset --hard <commit>
```

## Unstage file
```bash
git reset <file>
```

## Show Commit History
```bash
git log --oneline
```
