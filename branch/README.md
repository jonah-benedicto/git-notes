# Branch

## Create a branch
```bash
git branch <branch>
```

## Switch to a branch
```bash
git switch <branch>
```

## Create and switch to a new branch
```bash
git switch -c <branch>
```

## Rename a branch
```bash
git branch -m <old-name> <new-name>
```

## Delete a branch
```bash
git branch -d <branch>
```

## Delete a branch forcefully
```bash
git branch -D <branch>
```

## Delete a remote branch
```bash
git push origin --delete <branch>
```

## List branches
```bash
git branch -a
```
