# Revert

## Revert to Latest Commit
```bash
git revert HEAD
```

## Revert to Specific Commit
```bash
git revert <commit>
```

## Revert to Specific Commit
```bash
git revert HEAD~2
```

## Skip Commit Message Editor
```bash
git revert --no-edit
```

## Show Commit History
```bash
git log --oneline
```
