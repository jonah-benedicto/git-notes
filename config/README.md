# Config

## Set a global username
```bash
git config --global user.name "username"
```

## Set a global email
```bash
git config --global user.email "email"
```

## View current config
```bash
git config --list
```

## Use a different config level
```bash
git config --system
```
```bash
git config --global
```
```bash
git config --local
```
