# Rebase

## Rebase onto another branch
```bash
git rebase <branch>
```

## Start an interactive rebase
```bash
git rebase -i <base>
```

## Continue a rebase
```bash
git rebase --continue
```

## Abort a rebase
```bash
git rebase --abort
```

## Skip the current commit in a rebase
```bash
git rebase --skip
```
