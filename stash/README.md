# Stash

## Stash All Files
```bash
git stash
```

## Stash All Files with Message
```bash
git stash push -m "message"
```

## List All Stashes
```bash
git stash list
```

## Show Stash
```bash
git stash show stash@{n}
```

## Apply Stash
```bash
git stash apply stash@{n}
```

## Pop Stash
```bash
git stash pop
```

## Drop Stash
```bash
git stash drop stash@{n}
```

## Clear All Stashes
```bash
git stash clear
```

## Branch Stash
```bash
git stash branch <branch> stash@{n}
```
